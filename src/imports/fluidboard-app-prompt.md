🔥 MASTER PROMPT (Paste into Figma AI)

Design a high-fidelity Android app called “FluidBoard” — a next-generation infinite AI-powered whiteboard app for stylus users. The experience should feel like a blend of Apple Freeform and Miro, but optimized for Android tablets and large phones with stylus support (S-Pen / USI pens).

🎯 Core Concept

FluidBoard is an infinite canvas idea system designed for:
	•	Brainstorming
	•	Mind mapping
	•	Sticky note clustering
	•	Visual thinking
	•	Design ideation
	•	School and MUN preparation
	•	Creative concept mapping

The interface must feel:
	•	Extremely fluid
	•	Minimal but powerful
	•	Professional but creative
	•	Smooth and responsive (120Hz feel)
	•	Designed for stylus-first interaction

⸻

🖌 1. Canvas & Drawing Experience

Infinite Canvas
	•	Fully infinite zoomable and pannable canvas.
	•	Smooth pinch-to-zoom with inertia physics.
	•	No boundaries.
	•	Canvas auto-centers on first content.
	•	Mini-map preview in bottom right corner (like Miro).
	•	Snap-to-grid toggle.

Background
	•	Default background: soft off-white (#FAFAFA).
	•	Subtle dotted grid pattern (light gray dots, 8px spacing).
	•	Option to switch between:
	•	Dots
	•	Lines
	•	Blank
	•	Graph paper
	•	Dark mode (charcoal background with soft light dots)

Stylus Experience (Very Important)

Pen strokes must feel:
	•	Ultra-fluid
	•	Zero-lag simulation
	•	Pressure-sensitive
	•	Tilt-sensitive shading
	•	Velocity-based stroke smoothing
	•	Adjustable thickness (1px–20px)
	•	Natural ink simulation (slight tapering at stroke ends)

Add:
	•	Fountain pen
	•	Marker
	•	Pencil (grain texture)
	•	Highlighter (semi-transparent)
	•	Eraser (stroke or pixel mode)

Include palm rejection indicator.
Show subtle glow under active stylus tip.
Haptic feedback simulation for drawing interactions.

⸻

🗂 2. Boards & Data Saving

Boards System
	•	Users can create unlimited boards.
	•	Boards shown in grid layout (like moodboard cards).
	•	Each board preview shows:
	•	Thumbnail snapshot
	•	Last edited time
	•	Number of elements
	•	AI improvement suggestions indicator

Include:
	•	Folder system
	•	Tags
	•	Search
	•	Smart search (AI detects keywords inside handwriting)

Data Storage

Design for:
	•	Auto-save every 2 seconds.
	•	Offline-first architecture.
	•	Local encrypted storage.
	•	Cloud sync toggle.
	•	Version history slider (scrubbable timeline).
	•	Restore previous versions.

⸻

🧠 3. AI Enhancement System

Add floating “✨ Improve” button.

AI Features:
	•	Clean up messy handwriting
	•	Convert sketches to polished diagrams
	•	Beautify mind maps
	•	Auto-align sticky notes
	•	Suggest layout improvements
	•	Convert hand-drawn arrows into clean vector arrows
	•	Convert rough UI sketches into wireframes
	•	Auto-color harmony suggestions
	•	Smart clustering of related sticky notes

When AI runs:
	•	Show soft animated shimmer effect over board.
	•	Show side-by-side before/after preview.
	•	Allow user to accept or reject.
